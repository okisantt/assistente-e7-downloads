# Assistente E7 — downloads

Aqui ficam somente os instaladores do **Assistente E7** para Windows. O código-fonte não é publicado.

- **Baixe sempre pela sua conta no site:** https://assistente-e7-site.vercel.app/conta.html
- O aplicativo só funciona com uma **assinatura ativa** (R$ 15,90 por 30 dias, no Pix).
- Funciona **somente no PC** com Windows 10 ou 11 (64 bits). Não funciona no celular.

## Como instalar

1. Baixe o arquivo `AssistenteE7.exe` da versão mais recente (em **Releases**, à direita).
2. Abra o arquivo e clique em **Sim** quando o Windows pedir permissão de administrador.
3. Clique em **Assinatura** e entre com o e-mail e a senha do site.
4. Siga a aba **Guia** do aplicativo: ela confere o seu PC sozinha e mostra o passo a passo.

**Não precisa instalar Python, Npcap, Fribbels nem nenhum programa extra.**

Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações** → **Executar assim mesmo**.
Para conferir se o arquivo é o original, compare o SHA-256 informado em cada versão.

Ferramenta independente, sem vínculo com a Smilegate ou com o Epic Seven.
